# YOLO-PCB-Reference

**选题：模板轻微错位时，如何帮助 YOLO 定位 PCB 缺陷，同时保留细小缺陷的信号？** 项目采用 DeepPCB 的六类水平框，做面向有正常模板的工业检测场景的针对性改进。主基线选 YOLO26s `detect`，与图中建议一致，本机 Ultralytics 8.4.172 已支持该模型。研究变量放在配对输入的构造上，四组共用同一检测器。适用于其他课题的方法流程可通过 Magpie 的 `YOLO Paper Analysis` 技能调用。

## 从问题到设计

一条正常铜线在模板里横移两像素，直接相减会沿边缘留下亮带。细小的断路同样可能表现为局部亮斑。如果对每个位置都尽量消掉差异，也可能削弱真正的缺陷。我们要检验的是，**由中心周围的线路判断是否采用校正，能否兼顾减少误报和保留异常**。已有研究覆盖了双图检测、配准和有条件地接受配准；这里具体考察判断区域的位置，以及它对框级检测的影响。[参考论文与重合点](docs/references.md)

| 实验组 | 输入与唯一变化 | 回答的问题 |
|---|---|---|
| A · `single` | 待检灰度图复制为三通道 | 单图检测器能做到什么程度？ |
| B · `raw` | RGB 三通道依次为待检图、原模板、同位置绝对差 | 引入模板及差分通道本身是否有用？ |
| C · `aligned` | 在 B 上估计一次全局平移，仅校正差分通道 | 普通平移校正已经能解释多少收益？ |
| D · `ring` | 在 C 上只对周围线路支持校正的位置采用校正残差，其他位置使用原始残差 | 排除中心的局部判据是否比 C 有额外价值？ |

`pcb_reference.inputs.make_input` 在骨干第一层卷积之前生成输入。主干的 Conv、C3k2、SPPF、C2PSA 负责提取特征；上采样和 Concat 融合尺度；第 16、19、22 层送入 Detect，对应步长 8、16、32。C 与 D 使用同一相位相关位移估计，最多接受每轴 8 像素并取整。D 在 15×15 邻域剔除中心 5×5，用剩余 200 个像素的平均绝对差判断，校正带来的改善超过 2 个灰度级才采用。窗口和阈值是起始设定。

## 复跑

在本目录的 PowerShell 中使用本机 `yolo` 环境。已下载的原始数据在 `data/DeepPCB`；换机器时从作者仓库克隆到该位置，并检出 `08e98c4db5922613fb97176eb3d6497d48260cb1`。四组完整数据均已生成，每组训练 900 对、验证 100 对、测试 500 对。准备命令遇到同名目录会退出以保护已有导出；以下命令会复用已有 `data.yaml`。

```powershell
Set-Location 'D:\Python\YOLO-PCB-Reference'
$py = 'C:\Users\BaiRong-NUC\.conda\envs\yolo\python.exe'
& $py probe.py
foreach ($arm in 'single','raw','aligned','ring') {
    if (-not (Test-Path "data/$arm/data.yaml")) { & $py prepare.py --arm $arm; if ($LASTEXITCODE) { throw "准备 $arm 失败" } }
}
```

正式对比从同一官方 `weights/yolo26s.pt` 开始，已核对 SHA-256 为 `646f8bc3fe0a656803d95c294f7852321748cb29d13466a1af8862e2db384a1b`，并用这份权重对四组各跑通一张验证图的 CPU 推理。下面的首组命令供启动训练时使用。其余各组只改 `--arm`。训练入口固定 seed、30 轮、batch 8、640、SGD，关闭会改写通道语义的色彩增强及 Albumentations 默认变换。权重和训练输出统一留在本项目。

```powershell
& $py train.py --arm single
```

先在开发集锁定操作点，再检验原模板和 ±1、±2、±4 像素水平/垂直平移。`prepare.py --arm ring --val-shift 2 0` 可生成仅验证模板有扰动的版本，同一训练权重在不同条件下分别评估。报告同一 IoU=0.50 下的召回率与每图误报数、六类结果、AP50–95、推理加预处理的端到端延迟；比较 B 对 A、C 对 B、D 对 C。小缺陷先按训练框面积的下四分位确定阈值，再应用于验证集。对 D 另做同尺寸实心窗口消融以检验「排除中心」的解释，展示固定工作点下的成功、无变化和失败例。DeepPCB 官方脚本使用严格 `IoU > 0.33`，应另表报告。若 D 与 C 相当，结论应保留普通校正已足够解释现象的可能。
